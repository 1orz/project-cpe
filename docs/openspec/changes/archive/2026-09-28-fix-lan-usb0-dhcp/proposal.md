# 提案：修复局域网口无法分发 IP / 打不开后台

## 问题

5G 壳「以太网 2」插上网线后，电脑拿不到 `192.168.66.x`，因而打不开 `http://192.168.66.1`。ADB 仍可用。

## 根因（真机核对）

1. 壳上网口走的是模块 USB gadget（RNDIS → `usb0`），不是独立 `eth1`。
2. 开机没有启用 ConnMan gadget tethering，也没有给 `usb0` 配 `192.168.66.1`。`/etc/route_test.sh` 存在但启动链不调用它。
3. `configure_usb_network()` 只在热切换 USB 模式时运行，`udx710` 启动时不拉起局域网。
4. 设备 `loader.sh` 用 `-H 192.168.66.1` 绑死监听地址；OTA 包只带 `udx710` 二进制和 `www/`，不覆盖 `loader.sh`。

## 已做临时处置

已在设备上执行（未改 `loader.sh`）：打开 gadget tether，给 `usb0` 配 `192.168.66.1` 并 `up`。重启后会丢。

## 修复目标

- `udx710` 启动时自动拉起 `usb0` 网关和 DHCP（OTA 可落地）。
- 不把默认路由改成 `192.168.66.2`，避免冲掉蜂窝上网。
- 不新增对外 HTTP API，不改架构。
